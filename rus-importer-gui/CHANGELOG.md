# История изменений

## 6.3.0 — универсальные CSV-шаблоны (28.10.2026)

- Любые заголовки, любое число колонок до 128; никакие `Name`, `File`, `Image` не обязательны.
- Поддержка существующих строк CSV, которые изначально выключены, чтобы не включить примеры случайно.
- Ручная настройка столбцов названия и вложения; добавление/удаление строк, прикрепление файлов.
- Кнопка «Открыть проект» для сохранённых сведений.
- Экспорт CSV без вложений; прочие поля не изменяются при экспорте.

## 6.2.0 — релизная подготовка (28.10.2026)

- Удалён устаревший неиспользуемый интерфейс и старые функции транслитерации.
- Исправлена переносимость сохранённых проектов: относительные пути к документам и шаблону, поиск файлов после переноса рабочей папки.
- Улучшено сохранение проекта: резервная копия и восстановление в случае сбоя.
- Ошибки чтения файлов и сохранения больше не маскируются успешными сообщениями.
- Освобождено место в интерфейсе: редактор строки открывается по выбору документа; показ папки результата после экспорта.
- Добавлены тесты повторного сохранения и переноса проекта, документация пользователя и сборка для публикации.
- Исправлен поиск CSV-шаблона: любые имена, автоматическое обнаружение TSV, выбор при нескольких вариантах, понятное сообщение для Excel `.xlsx`.

## 6.1.0

- Автоматическая очистка всех запрещённых символов в File и именах ZIP: латиница, цифры, дефис, подчёркивание, точка только перед расширением.
- Уникальные имена, неизменность поля Name и оригинальных файлов.

## 6.0.0

- Внешний CSV-шаблон вместо встроенного набора 14 колонок.
- Динамические колонки таблицы, массовая правка, сохранение порядка и разделителя шаблона, поддержка BOM и табуляции.

## 5.x

- Компактный интерфейс Rust, тёмная тема, редактирование столбцов, проект и ZIP; исправления совместимости импорта.
