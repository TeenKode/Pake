# RusDocumentImporter

**Портативная программа для Windows x64**, которая готовит CSV и ZIP-архив документов для импорта на сайт. Не требует установки и прав администратора.

## Быстрый старт

1. Распакуйте \`RusDocumentImporter.exe\` в любую папку.
2. Создайте рабочую папку с документами (PDF, DOCX и другими поддерживаемыми файлами).
3. Положите в эту рабочую папку CSV-шаблон от сайта, предпочтительно с названием \`component_import.csv\`. Шаблон **не встроен** в программу.
4. Откройте программу, нажмите **Папка** и выберите рабочую папку. При необходимости нажмите **Шаблон CSV**, чтобы указать нужный файл.
5. Отредактируйте таблицу или заполните значения массово.
6. Нажмите **Создать ZIP**. Результат: папка \`Готовые\` и архив \`Готовые.zip\`; при повторном экспорте создаются отдельные \`Готовые_2\` и т. д.

## Возможности

- Чтение внешнего CSV: любой порядок колонок, дополнительные поля, разделители \`;\`, табуляция или запятая; UTF-8 с BOM или без.
- Считывание одной строки значений по умолчанию из шаблона; демонстрационные подсказки «Укажите ...» не копируются.
- Автоматическое заполнение **Name** русским названием исходного файла и **File** безопасным латинским именем.
- В **File** и именах файлов ZIP только латинские буквы, цифры, дефис, подчёркивание и точка перед расширением. Поле **Name** сохраняет все исходные символы, включая скобки.
- Разрешение совпадающих имён добавлением \`_2\`, \`_3\` и т. д.
- Редактирование ячеек, боковая панель всех полей, массовое заполнение, отмена массовой правки, поиск и фильтр, изменение ширины колонок, светлая и тёмная темы.
- Сохранение проекта рядом с документами в \`RusDocumentImporter.project.json\`, восстановление после закрытия, поддержка переноса рабочей папки на другой компьютер.
- Экспорт CSV в UTF-8 **без BOM**, с сохранением структуры, разделителя и порядка колонок шаблона; ZIP содержит CSV и только отмеченные файлы.
- Исходные документы и внешний шаблон **никогда не переименовываются и не перезаписываются**.

## Условия использования шаблона

Файл шаблона должен содержать строку заголовков, в том числе **Name** и **File**. Остальные колонки берутся из шаблона сайта. Программа не добавляет поля, которых нет в шаблоне. Если в рабочей папке несколько CSV, используйте кнопку **Шаблон CSV** для выбора правильного файла.

Образец 14-колоночного шаблона находится в \`examples/template_example.csv\` **только для примера**. Для импорта на реальный сайт используйте его актуальный шаблон.

## Интерфейс

Кнопка **Папка** выбирает документы; **Шаблон CSV** — внешний шаблон; **Обновить** перечитывает шаблон и добавляет новые документы с сохранением ранее заполненных значений; **Массовая правка** заполняет или очищает выбранную колонку; **Все столбцы** показывает полный набор колонок; **Поля справа** показывает редактор строки. После экспорта используйте **Показать результат**.

Горячие клавиши: \`Ctrl+S\` сохранить проект; \`Ctrl+E\` создать ZIP; \`Ctrl+O\` выбрать папку; \`F5\` обновить список.

## Перенос и обновления

Для обновления замените только \`RusDocumentImporter.exe\`. Данные документов, шаблон и \`RusDocumentImporter.project.json\` остаются на месте. Для переноса всей рабочей папки скопируйте её содержимое целиком; проект использует относительные пути.

## Система и безопасность

- Windows 10/11 x64; для графического окна нужен работоспособный видеодрайвер.
- Не требует Python, Node.js, установленного Rust, отдельного сервера, администратора или установки.
- Программа не отправляет файлы в интернет. Сборки не подписаны сертификатом: Windows SmartScreen может запросить подтверждение.
- Архив рассчитан на импорт, но проверку правил конкретного сайта пользователь выполняет самостоятельно.

## Сборка из исходников

В Windows с Rust stable и Visual Studio C++ Build Tools:

\`\`\`powershell
cd rus-importer-gui
cargo test --release
cargo build --release
\`\`\`

Результат: \`target/release/rus_document_importer_gui.exe\`.

Пакет подготавливается GitHub Actions. Примечание: автоматические тесты проверяют работу локальной программы и архива, но не выполняют загрузку на сторонний сайт.
