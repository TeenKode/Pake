# RusDocumentImporter 6.4.0

Портативная версия для Windows 10/11 x64. **Установщик не нужен.**

Внутри: один `RusDocumentImporter.exe`, инструкция на русском, список изменений, GPLv3 и пример CSV.

## Основные функции
- Любой CSV с любым названием и любыми заголовками принимается без обязательных колонок. Доступны необязательные назначения колонок названия и вложения.
- Редактирование любых колонок, поиск, массовое заполнение, проверка имён файлов.
- Русское название `Name` сохраняется без изменений; имя `File` транслитерируется и очищается от спецсимволов.
- CSV в UTF-8 без BOM, ZIP только с отмеченными документами.
- Проект сохраняется и переносится вместе с рабочей папкой. Добавлена отдельная кнопка «Открыть проект».
- Строки-примеры из входного CSV не включаются в экспорт автоматически.

**Важно:** результат импорта на сторонний сайт зависит от его правил. Используйте актуальный шаблон, предоставленный сайтом. Сборка не подписана цифровой подписью.

Новые возможности 6.4: удаление строк с отменой, выбор отображаемых колонок и вставка нескольких строк из Excel через Ctrl+V в таблицу.
